📍 GPS is blocked in this view — here's how to get live location working

The message “Origin does not have permission to use Geolocation service” means the preview frame around this page is blocking GPS — it's not your phone's GPS failing. Live GPS works when the page is opened directly in Safari or from your Home Screen icon, not inside the in-app preview.

  1. Best fix: Open this app from your Home Screen “Chicago Map” icon (or open its link directly in Safari). Tap Use my location there and choose Allow While Using App.
  2. Check iPhone settings: Settings → Privacy & Security → Location Services → On, then Safari Websites → While Using the App and turn Precise Location on.
  3. In Safari: tap aA in the address bar → Website Settings → Location → Allow, then reload and tap Use my location again.
  4. Right now, without GPS: tap 👆 Tap map to set my location above, then tap anywhere on the map — or drag the 🚶 walker — to trigger the same walk-near pop-ups.
